# Osaamispolku – prototyyppi

Osaamisperustainen malli peruskouluun: numeroarvostelun 4–10 tilalla taidot, jotka oppilaan pitää kunakin vuonna osata. Jokaisesta taidosta on oppilaan sivu harjoituksineen, opettajan sivu (tuntirunko, virhesanakirja, viisi tulostettavaa koeversiota vastausavaimineen) ja huoltajan näkymä.

**Esittely:** https://teresammallahti.github.io/Osaamispolku/

- `4lk/` – 4. luokka, kaikki oppiaineet
- `7lk/` – 7. luokka, matematiikka

Sivusto on staattinen: ei palvelinta, ei kirjautumista, ei tietojen tallennusta. Kaikki henkilöt ja paikat ovat kuvitteellisia. Oppilaiden edistyminen taululla on keksittyä esimerkkidataa.
